# Process

Samah’s typical engagement flow:

1. **Discovery** — goals, audience, constraints, success definition
2. **Research** — channels, competitors, opportunities
3. **Strategy** — priorities, messaging, KPIs
4. **Execution** — campaigns, content, creative systems
5. **Optimization** — test and improve what works
6. **Reporting** — clear reporting so decisions stay grounded

Visitors can book a free consultation to start with Discovery.
