# Samah Portfolio Frontend

Decoupled Next.js 15 frontend for the premium portfolio experience. Does not modify the Laravel app.

## Develop

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

See [PROJECT_PROGRESS.md](./PROJECT_PROGRESS.md) for status, decisions, and changelog.
